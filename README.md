# sFTP Studio

A fast dual-pane SFTP client and terminal for Windows.

## Download

Get the latest installer from the [Releases page](../../releases/latest).

- `sFTP-Studio-<version>-setup.exe` - installer (recommended, auto-updates)
- `sFTP-Studio-portable.exe` - portable, no install

Each release includes `SHA256SUMS.txt` so you can verify your download.

This repository only hosts release downloads.
